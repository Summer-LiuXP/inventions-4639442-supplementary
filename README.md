# Supplementary Data and Code

## Article

**Evaluating Cloud–Edge Model Evolution for Distribution-Transformer Oil-Temperature Forecasting Across Stable and Regime-Shifted ETT Traces**

Manuscript ID: `inventions-4639442`

## Package contents

The file `inventions-4639442_Supplementary_Data_and_Code.zip` contains:

- public ETT datasets;
- experiment implementation and configuration files;
- reviewer-requested ablation and sensitivity experiments;
- group and total gradient-example audits;
- paired statistical tests and confidence intervals;
- generated predictions and result tables;
- figures and reproduction instructions;
- SHA-256 checksums for file verification.

## Reproducing the experiments

Download and extract the ZIP file, then follow the instructions in `Supplementary_Data_and_Code/README.md`.

Main scripts:

- `run_experiment.py`
- `run_reviewer2_controls.py`

## Data provenance

The public ETT data were obtained from the ETDataset/Informer repository:

https://github.com/zhouhaoyi/ETDataset

Users reusing the raw ETT data should cite the original Informer paper.
